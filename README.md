# PrepRoom

Privacy-first interview rehearsal coach for TV, built for Amazon Vega.

> **PrepRoom doesn't need to record you to help you improve.**

PrepRoom is a TV-first interview rehearsal experience designed around a simple loop:

**Goal → Rehearse → Evidence → Improve → Retry**

The experience focuses on practicing interview communication without requiring the user's face or voice to be recorded.

## Current prototype

The current prototype is built with:

- Amazon Vega
- React Native
- TypeScript
- Vega Virtual Device
- Jest / React Native Testing Library

The prototype focuses on the TV interaction model, remote navigation, visual hierarchy, 10-foot readability, and the core rehearsal experience.

## Prerequisites

- macOS
- Node.js 20+
- Amazon Vega SDK
- Vega CLI
- Vega Virtual Device
- VS Code with Vega Studio

The project was developed and validated with Vega SDK `0.24.9914`.
